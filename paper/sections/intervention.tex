\section{Correcting invariant drift improves rollouts}
\label{sec:intervention}

The recovered $C$ stays nearly constant along observation-conditioned trajectories, but it drifts
when the model rolls forward on its own. If that drift reflects a real model error, correcting it
should improve prediction. If $C$ is only a fitted statistic, enforcing it should simply perturb the
rollout.

At every imagined step, we project the latent state back toward the level set defined by its initial
value:
\begin{equation}
z \leftarrow z - \alpha\bigl(C(z)-C_0\bigr)\frac{\nabla C(z)}{\|\nabla C(z)\|^2},
\label{eq:edit}
\end{equation}
where $C_0$ is the value at the first encoded state. We map the correction back through $P$, leaving
the part of $h$ outside the extracted subspace unchanged. The intervention runs inside the
imagination loop; it does not modify the decoder, and we never retrain the model.

\paragraph{Scoring.} We use the same fixed grid $\alpha \in \{0, 0.05, 0.1, 0.2, 0.4\}$ for every arm
and score the slope of rollout error across the full grid. Selecting the best $\alpha$ after seeing
the curve would give each arm five chances to look good; the slope uses all five points. We measure
rollout quality by pixel mean squared error against held-out video over 50 imagined steps.

The scalar $C$ is fitted on the same 52 held-out trajectories used to evaluate the edit, so the
absolute intervention numbers are within-sample for the fitted scalar. The random-constraint arm
uses the same evaluation setting, so the comparison between recovered and random constraints remains
matched.

\paragraph{Controls.} We compare three interventions. First, we enforce each conservative model's own
recovered $C$. Second, we enforce a random polynomial from the same degree-4 basis, matched in norm.
Third, we enforce each damped model's own recovered $C$. We draw 20 random polynomials and apply the
same 20 to each of the three conservative models, giving 60 model--constraint evaluations from 20
distinct random constraints.

Figure~\ref{fig:three}c shows the dose response. At the strongest projection, enforcing the recovered
constraint lowers rollout error by 2.9\%, 3.3\%, and 3.5\% across the three conservative models.
Across the 60 random-constraint evaluations, the median change is $+53.9\%$, and only 7 of 60 lower
the error. Applying the same kind of edit to the damped models changes error by only $+0.5\%$. The
recovered arm also behaves much more consistently across seeds: its per-model slopes span $0.016$,
compared with $3.71$ across random evaluations.

The specificity result is not uniform. Figure~\ref{fig:null} compares each model with its own
20-draw null. For two models, no random constraint performs better than the recovered one. For the
third, 7 of 20 random constraints also lower error, and the best random draw reaches $-21.9\%$,
compared with $-2.9\%$ for the recovered constraint. We do not know why this seed behaves
differently.

The intervention result is therefore narrow but consistent: enforcing the recovered invariant
improves all three conservative models by 2.9--3.5\%, while matched random constraints usually hurt.
The improvement is specific to the recovered invariant on two models, but not on the third.
